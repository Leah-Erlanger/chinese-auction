# Chinese Auction

אתר למכירה סינית: רכישת כרטיסים, צפייה במתנות והגרלה וניהול מצד מנהל.

## מה האתר עושה
- צפייה במתנות, עם סינון ומיון
- רכישת כרטיסים
- הרשאת מנהל להגרלת הכרטיסים ולפרסום הזוכים

## טכנולוגיות
- **צד לקוח:** Angular
- **צד שרת:** ASP.NET Core Web API (עם ADO.NET ו-DTO)
- **מסד נתונים:** SQL Server

## מבנה הפרויקט
- `src/app` - צד הלקוח (Angular)
- `Controllers`, `Models`, `Services`, `Repositiers` - צד השרת
- `Migrations` - מבנה מסד הנתונים
